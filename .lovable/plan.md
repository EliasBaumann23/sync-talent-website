# Restructure the Knowledge Hub landing page

## Scope
Modify only the main Knowledge Hub landing page. Preserve every publication file, article URL, article page, citation, reference, route, and existing SEO metadata.

## Implementation
1. Replace the current directory-style header and placeholder-heavy grid with an editorial hero using the approved copy and a subtle jump link to latest intelligence.
2. Select one real, substantial published article from the existing registry as the featured publication and display only its verified metadata.
3. Build a latest-intelligence section from published registry entries only, ordered by reliable publication date. Exclude the featured article from duplicate display and never show drafts as live.
4. Add five restrained topic controls with simplified user-facing labels while mapping them to the existing underlying publication categories, preserving filter behavior without changing article metadata.
5. Finish with a quiet editorial transition linking to Executive Search and the Atlas Method, with no booking or newsletter CTA.
6. Verify the page at desktop and mobile sizes, confirm both required Atlas Notes remain reachable, and check the current build output.

## Design
Use the existing navy, white, turquoise, typography, spacing, and border tokens. Establish clear hierarchy through scale and layout rather than imagery, icons, or methodology-style diagrams.
